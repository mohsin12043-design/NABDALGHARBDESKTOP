Damaged and Missing Vehicle Stock

Use this section when stock is damaged inside the vehicle or cannot be found during counting.
STOCK ADJUSTMENT
Select a product to load the available quantity automatically.
Photo will be compressed before it is saved with the movement record.
The quantity is removed only from Vehicle Stock. Main Warehouse stock is not increased. A VDM or VMS reference and company PDF document are created.

Correct Damage or Missing Entry

The original record stays in history. Stock is adjusted through a correction record.
Example: original damaged quantity 80, correct quantity 8. The system restores 72 pieces to Vehicle Stock and keeps both references in the audit history.

Return Vehicle Stock to Main Warehouse

Select the vehicle and product. Current vehicle quantity loads automatically. A return reference and company PDF document are created after submission.
WAREHOUSE RETURN
Select a product to load its available vehicle quantity.
Submitting a return reduces the selected Vehicle Stock, increases Main Warehouse stock, records the user and time, and opens the return document for Print or Save PDF.
