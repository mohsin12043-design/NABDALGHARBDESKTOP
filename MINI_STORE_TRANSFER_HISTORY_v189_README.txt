Nabd Al-Gharb Desktop v1.8.9 - Mini Store Transfer History and Documents

Added:
1. Automatic Mini Store movement references:
   MTX = Main Warehouse to Mini Store transfer
   MRT = Mini Store return to Main Warehouse
   MDM = Damaged Mini Store stock
   MMS = Missing Mini Store stock
2. Existing old Mini Store movements receive references automatically.
3. Transfer history now shows reference, current Mini Store balance, movement type and user.
4. Movement filter added for Sent, Returned, Damaged and Missing records.
5. Reference numbers are clickable in Movement History and Settlement Report.
6. Clicked references open the company bilingual document layout.
7. Movement documents include product, quantity, Mini Store balance before/after, Warehouse effect, user and date.
8. Print / Save PDF is available from the document preview.
9. Cashiers can only open documents for their assigned Mini Store.
10. New transfers and settlement movements store before/after balances and reference numbers.

No new Supabase SQL is required.
Windows installer was not built in this environment. Build once after all Mini Store modules are complete.
