Nabd Al-Gharb Desktop v1.9.2
Mini Store Dedicated Stock Return

Added:
1. Separate Return Mini Store Stock to Main Warehouse section.
2. Mini Store and product selection limited to assigned locations.
3. Available Mini Store quantity loads automatically.
4. Full available quantity fills automatically and can be reduced for a partial return.
5. Return reason and optional remarks.
6. Mini Store stock decreases and Main Warehouse stock increases.
7. Automatic MRT reference number and clickable company PDF document.
8. Before and after balances for Mini Store and Main Warehouse are saved.
9. Inventory-only users cannot access the return section.
10. Damage and Missing remain separate and do not increase Main Warehouse stock.

No new Supabase SQL is required.
Windows installer was not built in this environment. Build it once after all Mini Store modules are complete.
