BACKUP, RESTORE AND RESET SAFETY

1. Complete backup includes all local app data plus available cloud tables.
2. Restore merges records and does not delete existing records.
3. Production Reset is Admin-only and requires internet, confirmation text and Admin password.
4. A complete backup must succeed before the reset can continue.
5. Customer Ledger, Inventory and Products, Employees, Khurooj, stock locations, company settings, Cashier users and permissions remain protected.
6. Only transaction data listed on the reset screen is cleared.
7. No manual SQL is required for this release.
