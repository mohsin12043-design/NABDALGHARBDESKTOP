Nabd Al-Gharb Desktop company details update

Open Settings to enter the company address in English and Arabic. Select Save Company Address. The saved address is used in new PDF and print document headers, including Tax Invoice, Cash Receipt, Inventory, stock, ledger, and report documents.

The Tax Invoice seller details also have a Save Company Address for All Documents button. Use it if you change the seller address while preparing an invoice.

In Settings, Company Mobile Number now includes a Show company mobile number on PDF and print checkbox. Save the number and checkbox together. Turning it off hides the company mobile number in document layouts. Customer phone fields are not changed. A document reprinted later may use the current company header settings.

Tax Invoice company header uses equal-width English and Arabic columns with the logo centered. Salary and Advance slip headers also use the saved bilingual address.

Company address and mobile visibility settings are saved locally and included in cloud synchronization. All 23 desktop modules were retained. No customer, invoice, stock, or employee records were deleted or reset.

This ZIP contains updated desktop source. A Windows installer must be built through the project's GitHub Actions workflow before installation.
